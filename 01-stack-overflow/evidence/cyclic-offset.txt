# 偏移确定的完整过程：gdb 断点实测 + pwntools cyclic_find 反查
# 目标：确定从 vuln() 的 buf 起始到「返回地址槽」需要多少填充字节

## 1. 生成 De Bruijn 模式并喂给程序
   cyclic(200, n=8) 前 16 字节 = b'aaaaaaaabaaaaaaa'

## 3. 用 pwntools cyclic_find 反查返回地址槽内容对应的偏移
   gdb 读到 ret 槽内容 = b'jaaaaaaa'
   cyclic_find(ret槽内容, n=8) = 72

## 4. 结论
   OFFSET = 72 = buf[64] + saved rbp[8]
